# 小算纸 · kl-math

React + TypeScript + Vite + Tailwind CSS 的纯前端数学练习生成器，无需后端。

## 开发

需要 Node.js 22.18+ 或 24+。

```bash
npm install
npm run dev
```

`npm run build` 检查类型并构建至 `dist/`，`npm run preview` 预览构建产物，`npm test` 检查出题算法与分页边界。

## 功能与规则

- 数字范围 10–10000。可按题数生成 1–500 题，或选择铺满 1–10 页；铺满模式随列数、字号、页眉设置自动重新生成题目，保持指定页数铺满。
- 加减法、纯加法、纯减法、乘法、除法、九九表内简单乘除法、三项混合运算。
- 所有数字、结果及混合运算的中间结果均为所选范围内的非负整数；除法保证整除且除数非零。
- 普通乘除法使用至少为 2 的因数；九九表题型允许 1–9 的因数。
- 优先避免相同算式；组合数量不足时允许重复，并在预览下方提示。
- 加减法、纯加法与纯减法支持下拉选择 2–5 连（数字个数），默认 2 连；乘除法与混合运算保持原有规则。
- 1–5 列、12–64 px 字号（逐像素调节及快捷选项）、显示答案；排版即时更新，内容设置点击“生成新题目”应用。
- 每页右下角依次显示日期、用时、错误个数 / 总个数、修正用时与页码。总个数自动印出本页实际题数（末页不足一页时按实际数量），其余记录留空手填。页眉、品牌页脚、题目序号默认隐藏，可单独开启；开启页眉后可修改标题。
- 纸张内边距为 10 mm，紧凑行距；默认 24 px、3 列时，每页可容纳 66 题。
- 以固定 A4 尺寸分页，窄屏等比例预览。过长算式会缩小适配列宽。

## 打印

点击“打印练习”或按 Ctrl+P（macOS 为 Cmd+P），选择 A4 纵向、100% 缩放，关闭浏览器页眉页脚。可选择“另存为 PDF”。页面设置了零页边距和内部安全留白；打印时隐藏设置面板，保留练习纸的字体、颜色、布局与分页。实际颜色和纸张位置仍取决于打印机与浏览器设置。

## 代码

- `src/generator.ts`：出题与分页计算。
- `src/App.tsx`：设置面板、预览和打印入口。
- `src/styles.css`：屏幕、移动端与打印样式，接入 Tailwind v4。
- `src/generator.test.ts`：出题边界与数学正确性测试。
